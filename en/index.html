FEATURES

반복 작업을 맡겨 두세요

쉬운 것부터 똑똑한 것까지, 필요한 만큼만 꺼내 쓰세요.

그림 찾아 누르기좌표가 아니라 그림으로 찾아요. 창을 옮겨도 다시 찾아내요.
🔴 녹화로 만들기직접 클릭·키 입력을 해 보이면 그대로 단계가 돼요. 이름도 알아서 지어요.
가려 둔 창에서도대상 창을 정하면 다른 창 뒤에 숨겨 둔 채로 돌려요. 그동안 PC는 다른 일에.
그룹·흐름 정리단계를 그룹으로 묶고 ☑/☐ 로 켜고 꺼요. 찾으면 이동, 못 찾으면 다시 하기도.
👁 감시 프리미엄화면을 지켜보다 조건이 맞을 때만 실행해요. 그동안 작업은 잠시 멈췄다 이어서.
⏰ 예약 프리미엄정한 시각에 작업을 바꾸거나 시작·종료해요. 매일 아침 출석 체크도.
문자·색으로 찾기 프리미엄화면 속 글자를 읽어 찾거나, 특정 색이 보일 때 눌러요.
언제든 F10 정지키 하나로 즉시 멈춰요. 마우스를 직접 잡으면 손을 뗄 때까지 기다려요.

지켜보다가, 필요할 때만

체력이 낮아지거나 알림 창이 뜨는 순간처럼, 정해 둔 그림이 보이면 그때만 따로 정한 동작을 해요.

  • 여러 감시 항목을 동시에 지켜봐요
  • 감시가 도는 동안 작업은 하던 단계를 마치고 잠시 멈춰요
  • 같은 상황이 연달아 와도 쉬는 시간(쿨다운)으로 조절해요

정한 시각에 알아서

아침 6시엔 출석 체크, 밤 11시 30분엔 프로그램 종료처럼 시간표를 짜 두면 그대로 해요.

  • 예약 안에 단계를 바로 만들어 실행해요
  • 작업 중 원하는 그룹만 골라 실행할 수 있어요
  • 끝나면 디스코드·텔레그램으로 알려 줘요

FAQ

궁금한 점

정말 무료인가요?

네. 그림 찾아 누르기, 녹화, 그룹, 가려 둔 창에서 돌리기 같은 기본 기능은 기간 제한 없이 무료예요. 감시·예약·문자/색 찾기·메시지 보내기가 필요할 때만 프리미엄을 쓰면 돼요.

어떤 PC에서 되나요?

Windows 10 · 11 (64비트) 에서 돼요. 맥과 휴대폰은 지원하지 않아요.

창을 옮기거나 해상도가 달라도 되나요?

좌표가 아니라 그림으로 찾기 때문에 창 위치가 바뀌어도 다시 찾아내요. 화면 배율이나 해상도가 크게 바뀌면 그림을 한 번 다시 찍어 주세요.

매크로가 도는 동안 컴퓨터를 써도 되나요?

대상 창을 지정하고 실행 방식을 고르면 그 창을 가려 둔 채로 돌릴 수 있어요. 실제 마우스를 쓰는 방식이라도 사용자가 마우스·키보드를 잡으면 손을 뗄 때까지 기다렸다가 이어서 해요.

멈추고 싶을 땐요?

F10 을 누르면 바로 멈춰요. 단축키는 설정에서 바꿀 수 있어요.

만든 매크로를 친구에게 줄 수 있나요?

[📁 파일 ▾] → 저장하면 단계와 그림이 .spk 파일 하나에 담겨요. 그 파일을 보내 주면 그대로 불러와 쓸 수 있어요.

게임에 써도 되나요?

게임이나 서비스마다 자동 입력 프로그램을 금지하는 약관이 있을 수 있어요. 쓰려는 곳의 약관과 규정을 먼저 확인하고, 본인 책임 아래 사용해 주세요.
